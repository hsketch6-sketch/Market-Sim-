# Market Sim — 30 Year Exchange

A fictional, educational multiplayer stock-market simulation. The server creates 100 fictional companies (tickers A, B, C, ...), 10 themes, clue news, public news, theme spillovers, baseline bots, a FOMO meter, and a shared 30-year simulated timeline.

## Requirements
- Node.js 18 or newer (built-in modules only; no `npm install` needed).
- A desktop browser.

## Run on Windows
1. Extract the ZIP to a folder, for example `C:\Users\YourName\Downloads\market_sim`.
2. Open PowerShell in that folder.
3. Run:
   ```powershell
   node server.js
   ```
4. Open `http://localhost:3000` in your browser.
5. Choose a nickname and join.

The server creates `market-state.json` automatically and saves the shared market state there. Keep the terminal window open while playing.

## Multiplayer on the same Wi-Fi / LAN
1. Start the server on one computer with `node server.js`.
2. Find that computer's local IPv4 address in Windows using `ipconfig`.
3. Other devices on the same network can open `http://HOST-IP:3000` if the host firewall allows Node.js on the private network.
4. Everyone must use the same host address to share the market.

This is LAN-capable, not an internet-hosted service. Internet multiplayer requires hosting the Node.js server on a reachable server and configuring network access. Do not expose the development server publicly without adding proper authentication, rate limits, and deployment security.

## Core rules
- All players share prices, news, and the market day.
- Anyone can advance the shared simulation by one trading day.
- A simulated day advances all company prices, bots, hidden project progress, and news.
- News templates are selected by theme. Clue news can affect hidden fundamentals without directly moving prices; public news moves the affected company's price and may spill over to its theme.
- Related companies may move together, but not every company in a theme is guaranteed to rise or fall.
- Buy and sell orders execute immediately at the current simulated price plus/minus a 0.10% fee. No short selling.
- At FOMO 100, purchases are restricted to stocks up at least 8% over the recent five-day window. Selling and holding cash remain possible.
- 30 years are represented by 7,560 simulation days (252 trading days per year).

## Important prototype limitations
- This is a first playable prototype, not a production-ready public multiplayer service.
- Prices are generated by a procedural model, not real market data.
- Server state is stored locally in one JSON file. Back up `market-state.json` if you want to preserve a run.
- Any player can advance the shared day. A future version should add host/admin controls, rooms, authentication, better persistence, and transaction logs.
- The simulation's event probabilities and effects are initial game-design choices, not calibrated economic forecasts.
